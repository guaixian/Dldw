# dldw 隧道白名单（模板）
#
# 格式：  每行一个域名；# 开头为注释；空行忽略。
# 匹配：  "github.com" 匹配 github.com 及任意深度子域（a.b.github.com）；
#         "*.github.com" 仅匹配子域；".github.com" 含裸域名。
#         匹配基于点边界：github.com.evil.com 永远不会命中。
#         IP 字面量永不匹配（IP 目标由 SSRF 策略直接拒绝）。
# 热更：  服务端每 30s 检查一次文件改动，保存即生效，无需重启。
# 版本：  可用 "# version: <tag>" 声明版本；客户端 doctor 会比对
#         本地固定的 whitelist_version 与此值，提示漂移。
# 位置：  服务端配置 whitelist_file 指向本文件（默认 <data_dir>/whitelist.txt）。
